# Playlist Maker — спринты 3–8

Учебный Android-проект на Kotlin и Jetpack Compose. Первый самостоятельный проект с дженериками находится отдельно: https://github.com/Xsize731/android-contacts.

## Приложения

- `app`: Playlist Maker — поиск по локальным трекам The Beatles, история запросов, настройки с Intent, детали трека, добавление в избранное и плейлисты, создание плейлистов.
- `bottomsheet-lab`: самостоятельная работа спринта 7. FAB открывает ModalBottomSheet; тап снаружи, свайп или кнопка закрывают панель.

## Состояние на конец спринта 8

Хранилище `DatabaseMock` существует в одном экземпляре, предоставляемом Koin. Данные живут в памяти до завершения процесса. Это намеренное ограничение текущего этапа. Сеть, Room, обложки из галереи и полноценный экран избранного относятся к последующим заданиям. Экран избранного сейчас — пустая заготовка, при этом переключение favorite в деталях работает.

Поиск не блокирует UI, запускается через 500 мс после ввода и имитирует трёхсекундную загрузку. Новые запросы отменяют предыдущие; очистка поля отменяет работу и сбрасывает результаты. История содержит до 10 уникальных последних запросов. Плейлист нельзя сохранить без имени. Добавление одного трека в один плейлист повторно не создаёт дубликаты.

## Архитектура

`domain` — модели и интерфейсы; `data` — mock-хранилище и реализации репозиториев; `ui` — экраны, состояния и ViewModel; `di` — зависимости Koin. Навигация сосредоточена в PlaylistHost; маршруты передают идентификаторы, а не JSON целиком.

## Сборка

Требуются JDK 21, Android SDK Platform 35 и Build Tools 35.0.0. Откройте корень в Android Studio либо задайте JAVA_HOME и ANDROID_HOME:

```powershell
.\gradlew.bat :app:assembleDebug :bottomsheet-lab:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:connectedDebugAndroidTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk` и `bottomsheet-lab/build/outputs/apk/debug/bottomsheet-lab-debug.apk`.

## Этапы

- feature/sprint-03: главный экран и Activity-переходы.
- feature/sprint-04: экран поиска, настройки и Compose-навигация.
- feature/sprint-05: MVVM, репозитории и Koin.
- feature/sprint-06: завершение поиска и промежуточная проверка.
- feature/sprint-07: отдельное приложение с FAB и ModalBottomSheet.
- feature/sprint-08: debounce, история, детали трека и плейлисты.

Перед отправкой преподавателю проверьте требования вашего вуза и заполните форму самостоятельно. Результат автоматических тестов не заменяет решение преподавателя.
